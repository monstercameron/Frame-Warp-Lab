## v0.19.0 — Visibility-guided selective tile repainting with ExecuteIndirect work admission

- Implemented the **P0 Inverse Rendering core**: decoupled full-resolution visibility + temporal cache reprojection from expensive pixel shading so only invalid, disoccluded, moving-object, or periodically aging `16×16` tiles are repainted on each source update, bounded by a configurable per-frame tile budget (`shaders/selective_tiles.hlsl`, `shaders/present.hlsl`, `src/renderer.h`, `src/renderer.cpp`, `src/runtime_state.h`, `src/main.cpp`, `src/cli.cpp`, `CMakeLists.txt`):
  1. **Pass 1 — Visibility + Temporal Cache Reprojection (`tile_vis_classify_cs.cso`, SM 6.0 `cs_6_0`, `[numthreads(16, 16, 1)]`)**: evaluates full-res visibility (`linear_view_depth`, `material_id`, `motion_vector`, and packed `R32_UINT` visibility word `material_id | (age << 8) | (surface_hash << 16)`), reprojects into the exact preceding completed source slot's camera (`prev_slot.snapshot.camera`), verifies depth (`rel_z_err < 3.5%`), material ID, non-moving-object, and max cache age (`16` frames) consistency, copies bilinearly filtered cached color on hit (and seeds fallback color on miss for graceful deferral), runs SM 6.0 wave reductions (`WaveActiveCountBits` / `WaveActiveMax`) into groupshared tile counters, schedules dirty and phase-staggered periodic-refresh tiles via a lock-free `InterlockedCompareExchange` CAS loop into `dirty_tile_list_uav_` (`RWStructuredBuffer<uint>`), caps admission against `tile_budget_pct` (reserving top 25% of tight budgets for dirty/disoccluded tiles over periodic refreshes), and writes `tile_map_target` (`DXGI_FORMAT_R8_UINT`: `0=cached`, `1=dirty`, `2=periodic_refresh`, `3=deferred`).
  2. **Pass 2 — Indirect Selective Shading (`tile_shade_indirect_cs.cso`, SM 6.0 `cs_6_0`, `ID3D12CommandSignature` `ExecuteIndirect`)**: dispatches strictly `{ThreadGroupCountX, 1, 1}` workgroups directly from GPU-written `tile_indirect_args_uav_` (zero CPU readback stall), reconstructs 3D world position directly from Pass 1's depth + visibility buffer (no second raymarch), evaluates normals, procedural albedo, lighting, fog, and synthetic shading stress only for admitted tiles, and resets each shaded pixel's cache age to `0`.
  3. **Cross-queue D3D12 resource safety & readback telemetry**: transitioned `SourceSlot` idle readable states to `PIXEL_SHADER_RESOURCE | NON_PIXEL_SHADER_RESOURCE` (`ALL_SHADER_RESOURCE`) with `ALLOW_RENDER_TARGET | ALLOW_UNORDERED_ACCESS` on `color`/`depth`/`motion` so both the legacy graphics raster+VRS path and the new compute selective-tile path coexist cleanly on `scene_queue_` alongside concurrent `present_queue_` reads; added dedicated `scene_compute_heap_` (`25` descriptors), `tile_stats_readback_` (`total`, `cached`, `shaded`, `deferred`), and `t6` (`scene_tile_map_texture`) binding on `present_root_signature_`.
  4. **Controls, HUD & Diagnostics (`RuntimeState` v18 / CLI schema v13)**: added hotkey `U` and CLI `set <pid> selective_tiles on|off`, CLI `set <pid> tile_budget 10..100`, live tile-cache diagnostic visualization (`view=tiles`, hotkey `T`: green = cached, orange/red = dirty repainted, cyan = periodic refresh, magenta = budget-deferred with 16 px tile grid), HUD `TILE XX% DEF N` telemetry, and `selective_tiles` / `shaded_tile_ratio` / `total_deferred_tiles` reporting in `status` and `trace`.

  - Under very low GPU utilization (e.g., `dlss_g_warp /2 + selective_tiles=on` or `occlusion_sweep` `tile_budget=15`), Blackwell DVFS downclocks GPU frequencies (raising reported raw `scene_gpu_us` to ~2.5 ms even though shader work is <12% of a frame), which is real power-saving hardware behavior rather than a compute regression.

## v0.4.1 — Harden shared-state ordering, GPU shutdown, and capability reporting

Widened `scene_time_ms` to 64-bit integer milliseconds and bumped `runtime_state_version` to 4.
- Added a `noexcept`-guarded GPU `flush()` in `~Renderer()` so GPU work drains during exception unwinding, guarded zero-size client viewports against division-by-zero, passed explicit Win32 operation names into `Handle`, and logged `scene_paused`, `scene_resumed`, and `scene_reset` events into the bounded runtime journal.
